A few things to know.

Is Path free and open source?

Path is open source under the Apache-2.0 license. You can explore, run, and contribute to the source on GitHub. If you choose a cloud AI provider, its usage costs and terms apply.

How do I get started?

On Windows, download the installer using the Install button above. For source setup, follow the repository guide. Running from source requires Node.js 22.14 or newer and npm 10 or newer. Some native dependencies may need C++ build tools.

Read the setup guide
Which platforms can I use?

Windows is the primary development target. macOS packaging is configured, but native runtime and permissions still need validation. Linux does not currently have an installer target.

Does everything stay on my computer?

Recordings, screenshots, and transcripts are stored locally. Capture and video processing do not require cloud AI. If you select a cloud provider or remote Ollama endpoint, the context needed for that operation is sent there. Cloud document generation does not send raw video or audio.

What should I know before using it?

Generated documents need your review. Markdown drafts are not autosaved, so copy or export them before switching recordings or closing Path. System audio and user-facing pause and resume are not yet available.
